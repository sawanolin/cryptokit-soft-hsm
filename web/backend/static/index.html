此操作不可恢复。请输入管理员密码，并输入 DELETE 确认。

生成对称密钥

生成 128 位 SM4 对称密钥。密钥记录与索引使用设备根密钥派生的 HMAC-SM3 完整性保护，密钥材料不会通过管理端导出。

服务操作确认

设置密钥有效期

有效期从密钥创建时间起计算。到期后显示告警，但不会自动停用密钥，便于课堂演示。

删除对称密钥

删除后，使用该对称密钥封装的数据将无法恢复。请输入管理员密码和 DELETE 确认。

恢复备份

当前密钥、文件、认证和设备状态会被备份内容替换。请输入管理员密码和 RESTORE 确认。
